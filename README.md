# 전화틈틈 v1.1.2

전화틈틈은 바쁜 일상 속에서도 짧은 틈을 활용해 통화 기록과 연락 흐름을 가볍게 확인할 수 있도록 만든 Android 앱입니다.

이번 v1.1.2 배포에는 일반 버전과 다이어트 버전 두 가지 APK가 포함되어 있습니다.

## 다운로드

GitHub Releases에서 아래 APK 중 필요한 버전을 받아 설치하면 됩니다.

| 파일 | 용도 | 크기 |
| --- | --- | ---: |
| `전화틈틈v1.1.2-stable.apk` | 일반 버전. 지도 관련 리소스를 포함한 전체 버전입니다. | 약 51.0MB |
| `전화틈틈v1.1.2.diet-stable.apk` | 다이어트 버전. 무거운 지도 라이브러리/리소스를 제외해 용량을 줄인 버전입니다. | 약 7.4MB |

용량이 부담되거나 지도 기능이 꼭 필요하지 않다면 다이어트 버전을 권장합니다. 전체 기능 구성이 필요하면 일반 버전을 설치해 주세요.

## 설치 방법

1. Releases 페이지에서 원하는 APK를 다운로드합니다.
2. Android 기기에서 APK 파일을 엽니다.
3. 보안 안내가 표시되면 `알 수 없는 앱 설치` 권한을 허용합니다.
4. 설치가 완료되면 전화틈틈을 실행합니다.

이미 이전 버전이 설치되어 있다면, 같은 버전 계열의 APK로 업데이트 설치할 수 있습니다. 설치가 되지 않는 경우 기존 앱을 삭제한 뒤 다시 설치해 주세요.


## 일반 버전과 다이어트 버전의 차이

일반 버전은 지도 관련 네이티브 라이브러리를 포함합니다. APK 내부 기준으로 `libnavermap.so`가 포함되어 있어 파일 크기가 큽니다.

다이어트 버전은 해당 무거운 지도 구성 요소를 제외해 설치 파일 크기를 크게 줄였습니다. 앱을 가볍게 배포하거나 지도 기능이 필요 없는 사용자에게 적합합니다.

## 주의사항

- Android 기기 환경에 따라 APK 직접 설치가 차단될 수 있습니다.
- 설치 전 기존 버전과 서명/패키지 구성이 다르면 업데이트 설치가 실패할 수 있습니다.
- 다이어트 버전은 지도 관련 기능이 일반 버전과 다르게 동작하거나 제한될 수 있습니다.
